Proposaly GA4 test site

A plain page that hosts the Proposaly web agent and Google Analytics 4. Use it to test Connect GA4 (server-side events) and the host-page events proposaly_conversation / proposaly_lead.

How to use

      
1. Open the chat bubble (bottom right) and send a message → proposaly_conversation appears above
         and, when the workspace's GA4 is connected, in GA4 → Reports → Realtime with transport: server.

         2. Give the agent your contact details so it creates a lead → proposaly_lead.
